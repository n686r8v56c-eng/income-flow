# Income Flow — MVP v1

독립 실행형 수익 창출 관리 앱. 7개 탭(홈/아이디어/프로젝트/실행/수익/분석/목표), 로컬 자동 저장, JSON 백업/복원, CSV 내보내기, 모바일 반응형 UI.

## 실행
`index.html`을 크롬/사파리에서 열거나 정적 웹사이트(Cloudflare Pages)에 그대로 업로드하세요. 별도 빌드가 필요 없습니다.

## 주의
- 현재 데이터는 **각 브라우저의 localStorage에만 저장**됩니다. 로그인·Supabase 실시간 동기화는 아직 구현되지 않았습니다.
- 목표 금액은 2026-11: 30만원, 2026-12: 120만원, 2027-01: 300만원으로 초기화되어 있으며 자유롭게 수정할 수 있습니다.
- 확정 매출은 `확정` 또는 `입금` 상태인 거래 중 앱·디지털 상품/전문 서비스/커머스만 합산합니다. 근로소득 및 투자소득은 별도 분류합니다.
- 재무 계산은 간이 관리용이며 회계·세무 신고용 확정값이 아닙니다.
- 기존 Flow 앱·GitHub 저장소에 변경을 가하지 않습니다.
